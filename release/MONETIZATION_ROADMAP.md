# MORROW 수익화 전환 로드맵

수익화의 최종 목적은 매출 자체가 아니라, 실제 만남을 더 안전하고 편하게 만드는
운영 원가를 지속해서 감당하는 것입니다. 따라서 초기에는 결제를 붙이지 않고
회원이 반복해서 사용할 이유와 신뢰 지표를 먼저 확보합니다.

## 단계별 목표

### 0단계 — 신뢰 가능한 핵심 경험 (현재)

- 카카오·네이버·구글 로그인, 만 20세 확인, 프로필 사진 검수
- 시간·생활권·취향 기반 추천과 설명 가능한 매치 점수
- 상호 관심 매치, 실시간 채팅, MORROW Sync, 장소·시간 약속 제안
- 차단·신고·안전 확인·약속 후 피드백
- 추천 카드에서 프로필을 최대 50명까지 무료 저장하는 `나중에 다시 보기`

기본 추천과 대화, 안전 기능은 유료로 잠그지 않습니다. 저장 목록은 재방문과
관심 전환을 확인하기 위한 무료 유지 기능입니다.

### 1단계 — 행동 신호와 리텐션 검증

다음 이벤트를 구현할 때 사용자 식별이 가능한 원문 대신 내부 익명 식별자로 집계합니다.
현재 저장소에는 이벤트 계약과 저장 기능만 있고, 분석 수집 파이프라인은 아직 연결하지 않았습니다.

| 이벤트 | 확인할 질문 |
| --- | --- |
| `profile_saved` | 다시 보고 싶은 사람이 실제로 생기는가? |
| `saved_opened` | 저장이 다음 방문으로 이어지는가? |
| `saved_to_like` | 저장 후 관심 전환 품질이 좋아지는가? |
| `match_to_sync_started` | 매치가 첫 대화로 이어지는가? |
| `date_plan_accepted` | 온라인 연결이 오프라인 약속으로 이어지는가? |
| `safety_feedback_submitted` | 안전 흐름이 약속 후에도 완료되는가? |

최소 4주 동안 코호트별 1·7·30일 재방문, 첫 매치까지 시간, 응답률, 약속
수락률, 신고율, 저장 후 전환율을 함께 봅니다. 신고율이나 이탈률이 악화되면
수익화 실험을 중단하고 신뢰 기능을 먼저 수정합니다.

### 2단계 — 선택형 가치 검증 (조건부)

1단계 지표가 안정된 뒤에만 다음과 같은 부가 가치를 작은 기능 플래그로 실험합니다.

- 바쁜 사용자를 위한 큐레이션 요청과 일정 정리 보조
- 저장·추천 목록을 더 빠르게 정리하는 고급 탐색 도구
- 약속 준비 체크리스트와 장소 후보를 함께 만드는 편의 기능

안전, 신고, 본인확인, 기본 매칭, 기본 채팅은 계속 무료로 유지합니다. 가격과
결제수단은 실험 전에 별도 약관·환불·세금·개인정보 검토를 거쳐 결정합니다.

### 3단계 — 과금 도입 전 운영 게이트

- 실제 사업자·고객지원·환불 담당과 약관, 개인정보 처리방침을 확정
- 결제 실패·중복 결제·환불·구독 해지·영수증 보관을 테스트
- 기능 플래그로 5% 이하의 제한된 그룹에서 시작하고 대조군을 유지
- 매출보다 매치 품질, 안전 신고율, 고객 문의 응답 시간을 함께 공개
- 결제 서비스 장애 시 무료 핵심 흐름이 계속 동작하도록 격리

현재 저장소에는 결제 API, 가격, 구독, 유료 잠금이 구현되어 있지 않습니다.
이 문서의 단계와 지표를 충족하기 전에는 결제 키를 추가하지 않습니다.
